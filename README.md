# Vuna Transport Mobile

React Native mobile client for Vuna Transport driver execution.

The app is intentionally an execution interface over Frappe and ERPNext. It will not become a second source of truth for stock, delivery quantities, accounting, vehicles, or trips.

## Planned first milestone

- Authenticated driver session
- Assigned trip and delivery-stop list
- Item-level delivery result capture
- Proof of Delivery submission
- Offline drafts with safe retry

The wider roadmap is maintained in the repository-level [`features.md`](../../features.md).
